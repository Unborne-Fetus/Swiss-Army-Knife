Connect Satisfactory to Swiss Army Knife

Waiting for the local monitoring service.

1. Install Ficsit Remote Monitoring through Satisfactory Mod Manager, then launch Satisfactory with the mod enabled.

2. Open in-game chat and enter /frm http start to start the monitoring server.

3. In the game's FRM mod settings, enable the HTTP/Web Server Autostart option so future launches connect automatically.
